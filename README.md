# Book Store

A simple and responsive **Book Store website** built using **HTML5 and CSS3**.
This project was created as part of my web development practice to strengthen my understanding of website structure, navigation, content organization, and CSS styling.

## 📌 Project Overview

The **Book Store** website is a practice project that provides a simple online bookstore-style interface.

The website organizes books into different categories and presents book-related information in a clean and user-friendly layout.

## 🌐 Website Sections

The website includes sections such as:

* **Home** – Introduction to the book store
* **About** – Information about the bookstore
* **Book Categories** – Different categories of books
* **Web Development** – Books related to web development
* **Programming** – Programming and coding books
* **Self Development** – Personal growth and self-improvement books
* **Contact** – Contact information

## 🚀 How to Run the Project

### Method 1 — Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your browser.

### Method 2 — Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Run the file using a browser or Live Server.
4. The Book Store website will open in your browser.
